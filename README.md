# Programming Fundamentals in C++

A collection of C++ programs covering core programming-fundamentals concepts, written during my Software Engineering degree at COMSATS University Lahore. Each file is a small, self-contained program demonstrating one concept.

## Concepts Covered

| File | Concept |
|---|---|
| `For Loop.cpp` | Basic `for` loops |
| `Nested For Loop.cpp` | Nested iteration and patterns |
| `Switch Statement.cpp` | Multi-way branching with `switch` |
| `Array.cpp` | Declaring and traversing arrays |
| `Dynamic Array.cpp` | Dynamic memory allocation with arrays |
| `Structures.cpp` | Defining and using `struct` |
| `Sum of numbers.cpp` | Accumulation with loops |
| `counter.cpp` | Counter logic |
| `Palindrome.cpp` | Palindrome checking algorithm |
| `prime.cpp` | Prime number testing |

## Build & Run

Compile any file with a C++ compiler, for example:

```bash
g++ "Palindrome.cpp" -o palindrome
./palindrome
```

## Purpose

These programs document my foundation-building phase in C++ — kept public as a reference for other beginners and as a record of my learning progression.
